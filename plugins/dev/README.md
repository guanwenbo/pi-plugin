# plugins/dev/ — 开发工具

放「写代码 / 改代码 / 交付代码」这条链路上的插件。

## 适合放

- Git：状态、提交、分支、diff 浏览
- 构建、测试、调试辅助（拉日志、跑用例、看结果）
- 代码检索、批量重构、目录结构分析
- 依赖 / 配置 / 环境检查

## 不适合放

- 纯 agent 工具能力的（没有开发场景绑定）→ `../agent/`
- 数据表格、CSV/JSON 查看 → `../data/`
- 文件管理器、进程、窗口这类桌面级操作 → `../system/`

## 目录约定

一个插件一个目录，目录名 = manifest id：`local.guanwenbo.<名字>/`，目录内自带 `README.md` 写清用途、权限范围、会对仓库做的写操作。
