# plugins/productivity/ — 效率与信息管理

放日常「减少重复劳动」的插件：待办、剪贴板、快速记录、检索。

## 适合放

- 待办 / 清单 / 提醒面板
- 剪贴板历史、常用片段、快捷插入
- 快速记录（随手笔记、收集箱）
- 跨来源的检索与聚合

## 不适合放

- 绑定编码场景的 → `../dev/`
- 写作成稿类 → `../writing/`
- 需要直接操作文件系统 / 进程 / 窗口的底层动作 → `../system/`

## 目录约定

一个插件一个目录，目录名 = manifest id：`local.guanwenbo.<名字>/`，目录内自带 `README.md`，写清数据存在哪（插件数据目录还是工作区）、会不会读剪贴板这类敏感内容。
