# plugins/misc/ — 未分类暂存

还不确定归哪一类的插件先放这里，**定型后请移到对应分类**，别让它长期沉淀。

## 什么情况下用

- 想法刚起步，还在试做什么形态
- 横跨两类、暂时难以归类

一旦插件稳定，按功能移到 `../dev/`、`../writing/`、`../productivity/`、`../data/`、`../system/` 或 `../agent/`，并同步更新 [`../README.md`](../README.md) 的索引表。

## 目录约定

一个插件一个目录，目录名 = manifest id：`local.guanwenbo.<名字>/`。移动目录不影响插件本身，manifest 的 `id` 与 `version` 保持不动即可。
