# plugins/writing/ — 写作与文档

放「产出文字内容」的插件：写稿、改稿、成稿。

## 适合放

- 公众号 / 长文写作、标题生成、风格化改写
- PRD / TRD / 技术文档的结构化撰写与校验
- Markdown 排版、目录、字数与引用检查
- 素材整理到成稿的流程（可由插件带技能文档实现）

## 不适合放

- 代码注释 / 提交信息生成 → `../dev/`
- 只是通用的文本处理工具（不绑定写作场景）→ `../agent/`

## 目录约定

一个插件一个目录，目录名 = manifest id：`local.guanwenbo.<名字>/`，目录内自带 `README.md`，写清适用文体、输出格式、以及是否会把内容写到工作区哪个路径。
