# plugins/data/ — 数据查看与处理

放处理「结构化数据」的插件：看、查、转、画。

## 适合放

- CSV / TSV / JSON / YAML / Excel 的查看与筛选
- SQLite / SQL 查询（只读优先）
- 数据清洗、格式转换、字段映射
- 图表与报表生成
- 日志 / 埋点的解析与统计

## 不适合放

- 纯文本处理（不涉及结构）→ `../agent/`
- 代码构建产物分析 → `../dev/`

## 目录约定

一个插件一个目录，目录名 = manifest id：`local.guanwenbo.<名字>/`，目录内自带 `README.md`。涉及数据库的必须写明是否只读、如何保证只读。
