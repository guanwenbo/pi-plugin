# plugins/system/ — 桌面与系统集成

放和操作系统 / 桌面打交道、或改变 PI-Desktop 自身外观与行为的插件。

## 适合放

- 文件与目录：浏览、批量重命名、查找、预览
- 进程、窗口、通知、开机项这类系统级操作
- 主题、外观、界面细节调整
- 与本机 CLI / 外部应用联动

## 不适合放

- 面向 agent 的能力（无系统副作用）→ `../agent/`
- 业务场景化的效率工具 → `../productivity/`

## 目录约定

一个插件一个目录，目录名 = manifest id：`local.guanwenbo.<名字>/`，目录内自带 `README.md`。

分类里权限风险最高的一档：`fs.write` / `fs.delete` 必须写清具体范围，禁止整树；对外部应用的调用要写明失败时的行为。
