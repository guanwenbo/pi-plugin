# plugins/diagram/ — 图示与结构可视化

放「画图」的插件：把结构、流程、交互关系画成人能看懂、也能继续改的图。

## 适合放

- 技术架构图、部署图、依赖关系图
- 业务建模：领域模型、实体关系、业务闭环
- 流程图、状态机、决策树
- 时序图、交互时序
- 白板 / 手绘风草图（Excalidraw 一类）

## 不适合放

- 数据图表（柱状/折线/饼图这类由数据算出来的图）→ `../data/`
- 纯文本的 Markdown 目录树、ASCII 图 → `../agent/`

## 和 `../data/` 的区别

`data/` 的图**由数据决定形状**（同一条 SQL 换数据图就变），`diagram/` 的图**由结构决定形状**（人工定义、可反复编辑）。

## 目录约定

一个插件一个目录，目录名 = manifest id：`local.guanwenbo.<名字>/`，目录内自带 `README.md`。

画图类插件容易引入较重的前端依赖：构建产物要一并提交（仓库即可安装），`node_modules` 不提交；字体等第三方资源需在 README 里注明来源与许可。
